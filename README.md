# Phần 1 (Phân tích - AutoFilter)
Giống như "Google Search của bảng tính", AutoFilter (Ctrl + Shift + L) giúp lọc nhanh dữ liệu, khoanh vùng chính xác thông tin (như loại mã độc, mức độ) giữa hàng nghìn bản ghi thô.

# Phần 2 (Triển khai hoàn chỉnh)


Word: Dùng Navigation Pane và tạo mục lục tự động (Auto TOC) cho báo cáo an ninh mạng.

Excel: Dùng hàm =VLOOKUP(TRIM(Lookup_value), ...) để loại bỏ khoảng trắng thừa, tra cứu chính xác từ cơ sở dữ liệu sang nhật ký hệ thống.

PowerPoint: Thiết kế sơ đồ chiến lược phòng thủ 3 tầng, tuyệt đối dùng font hiện đại (Montserrat hoặc Inter, không dùng Times New Roman) để hiển thị rõ khi chiếu
